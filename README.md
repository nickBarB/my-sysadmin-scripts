# Мониторинг ресурсов

Bash-скрипт каждые 10 секунд дописывает дату, состояние памяти, дискового пространства и нагрузку сервера в `monitor.log`.

## Требования

Linux, Bash и команды `free`, `df`, `uptime`, `date`, `sleep`.

## Запуск

```bash
chmod +x script.sh
./script.sh
```

Остановка — **Ctrl+C**. Запуск не требует `sudo`.

Интервал задаётся константой `INTERVAL=10` в `script.sh`.

## Результат

Лог создаётся рядом со скриптом, независимо от текущей папки запуска. Существующие записи сохраняются, новые добавляются в конец. Временная метка использует время сервера.

Просмотр из папки проекта:

```bash
cat monitor.log
```

## Файлы

- `script.sh` — скрипт мониторинга.
- `sample_output.txt` — пример формата лога с условной временной меткой.
- `.gitignore` — исключает рабочий файл `monitor.log` из Git.
